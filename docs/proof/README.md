# Bằng chứng kiểm chứng

Bằng chứng gameplay và headless Phase 1: [phase-1/README.md](phase-1/README.md). Tái lập bằng `npm run verify`; kiểm tra trình duyệt bằng `npm start` và `node scripts/browser-check.mjs`.

Mỗi bằng chứng cần nêu yêu cầu được kiểm tra, lệnh chạy, input, kết quả mong đợi, output thực tế và trạng thái đạt/chưa đạt. Lưu cấu hình máy với phép đo hiệu năng. Không sửa tay output để khớp mong đợi.

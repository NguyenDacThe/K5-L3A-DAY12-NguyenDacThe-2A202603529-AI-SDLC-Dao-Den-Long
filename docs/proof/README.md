# Bằng chứng kiểm chứng

Bằng chứng gameplay và headless Phase 1: [phase-1/README.md](phase-1/README.md). Checkout tagphase-1 trước khi chạy lại các lệnh của Phase1.

Bản hiện tại: [Phase 2](phase-2/README.md), tái lập bằng npm run verify. Bằng chứng Phase1 dùng checkout tagphase-1; lệnh ở main hiện tạo bằng chứng Phase2.

Mỗi bằng chứng cần nêu yêu cầu được kiểm tra, lệnh chạy, input, kết quả mong đợi, output thực tế và trạng thái đạt/chưa đạt. Lưu cấu hình máy với phép đo hiệu năng. Không sửa tay output để khớp mong đợi.
